## 2. 首轮理论审计

识别并区分以下事项：

- 已分离离子的保迹局域操作不改变电子无条件约化态。
- 两个 E1 光子保持宇称，原 2p→3d 双光子预期不成立。
- 论文中的约化 R-matrix 固定离子 1s，不能原样应用于本项目的 1s/2p 共振。
- ESSS 离散求积必须带权重，二维/三维谱 Jacobian 不同，离子通道的概率必须非相干求和。

详细推导在《物理与算法核验》。这些是项目假设审计，不记作“程序算出了论文错误”。

## 3. 已定位并修复的程序/数值问题

### D01：三维通量数组的轴顺序

**症状：**表面交换子测试报 `(surface,core)` 与 `(core,surface)` 无法广播。

**定位：**角通道张量经 einsum 后的转置次序错误。参考实现直接计算完整稀疏矩阵的 `H Θ ψ − Θ H ψ`，包含三个方向的速度规范项。

**修复：**使输出固定为 `(core_radius,surface_radius,angular_channel)`。之后与独立矩阵交换子逐元素一致。

**证据：**`results/surface_initial_test.log`、`tests/test_surface.py::test_3d_surface_commutator`。

### D02：有限终止时间的表面通量验收条件

**症状：**自由高斯波包的表面振幅与无限时 Fourier 振幅差约 0.001317，初版测试失败。

**定位：**T=180 时仍有慢速分量在内区，测试漏掉有限时间的内区投影项。解析波包独立给出该项后，`通量振幅 + 剩余内区振幅 = 完整振幅` 成立。不是将容差放宽到 10⁻³。

**修复：**测试有限时精确恒等式，左右两个出射方向分别核验。生产谱保留传播尾时收敛要求。

**证据：**同一失败日志；`test_free_packet_surface_amplitude_both_directions`。

### D03：离子反向传播使用了过粗的时间步

**症状：**一维提谱把表面降采样后的间隔 0.08 直接用于离子 split operator，第一通道峰偏到约 0.588。

**定位：**单步零场离子态相位与解析本征态传播对照。1s 能量相位误差分别约为：dt=0.08 时 0.002954；0.04 时 0.000733；0.02 时 0.000179；0.01 时 0.0000443。长时间累积不可忽略。

**修复：**离子反向传播细分为若干步，默认至少恢复到正向 TDSE 的步长，另扫描 2、4、8 个子步。相同原始表面数据的峰从 0.588 向 0.593 收敛。随后另行细化正向 TDSE 时间步，不能只修提谱而忽略源波函数误差。

**证据：**`results/1d_local/spectrum_initial.npz`、`spectrum_substeps*.npz`、`ionic_timestep_scan.json`。不删除错误版本来隐藏偏移。

### D04：高阶 irECS Laguerre 尾元的消减误差

**症状：**增加到 36 个外区点后，原始数值导数对角项导致非物理增长模，长时间波包基准出现溢出。

**定位：**通用重心插值导数通过行和求对角项，在最远 Laguerre 节点处是大数相消。对 `P(x)=x L_n^1(x)` 的节点，导数矩阵的多项式对角项有解析值：零节点为 −n/2，其余为 1/2。乘指数基后还要减去 1/2。

**修复：**使用该解析对角项，其余 FE-DVR 装配保持不变。36 点不再有增长自由模；自由波包内区 L² 误差约 1.46×10⁻⁶。高阶稳定性测试检查整个离散自由哈密顿量本征谱。

**证据：**`results/boundary_radau_failure.log` 与旧 JSON、`results/boundary_benchmark.json`、`test_high_order_irecs_has_no_exponentially_growing_free_modes`。

### D05：吸收基准自身的“大实盒子”还不够大

**症状：**改进 irECS 后，晚时刻误差停在约 3.5×10⁻⁴。

**定位：**宽动量高斯包的高动量尾部已在参考实盒子外边界反射。扩大参考盒子到 r=200 后，该平台消失，irECS 可继续随尾元阶数收敛。

**修复：**参考解本身也进行盒子检查；不把所有差异都归因于待检算法。

**证据：**`results/boundary_initial_failure.log`，最终基准记录参考径向点数 1205。

### D06：时间步与性能

一维 dt=0.04 只作为粗网格调试数据，不能凭范数近似守恒就判定谱准确。已执行更细正向时间步扫描，实际谱差见自动汇总表。生产配置采用论文量级 dt，仍要求用自身网格做收敛检查。

同时将固定势指数缓存，把二维动能指数拆为一维因子。`results/fft_benchmark.json` 记录本机同一 512² 算例的实际开销；优化前后单步输出受独立回归测试约束，不以改变物理模型换速度。

三维 Arnoldi 的重正交进一步改用 BLAS 的原生共轭转置，避免每次复制不断增长的 Krylov 基。`results/arnoldi_benchmark.json` 记录原版、共轭缓存版和 BLAS 版的同状态计时及输出差；差异约 1.5×10⁻¹⁶。长算例在检查点处停止后恢复以使用该等价优化，物理配置未改变。

### D07：文献图的定量对照与未闭合差异

直接提取原 PDF 图 3(a) 的矢量曲线和 TDSE 标记，按图中刻度校准能量与概率，没有拟合能量偏移。脚本为 `scripts/digitize_reference.py`，曲线、对照图和误差存于 `results/literature_comparison/`。论文作图的峰中心与采用精细模型阈值的 ESSS 相近；使用独立求出的模型能量进行比较，而不是将 0.600 固定为谱中心。

完整的一维提谱流程另用独立演化的离子乘 Volkov 波包测试，两通道相对谱误差约 1.5×10⁻⁵，见 `results/channel_flux_control/validation.json`。该合成对照明确标记为 synthetic，不计入真实 He 结果表。

细时间步一维 TDSE 相对平坦连续谱 ESSS 仍存在约 10% 线形差异，因此增大势截断半径和外区重复计算。最终差值以自动表格为准；未闭合的部分不能归为“论文错误”，也不能只通过平移谱线消除。

大外区复算把第一、二通道主峰恢复到约 0.596、0.595，归一化线形 L¹ 差下降到约 0.8%、3.0%。这将主要偏移定位在有限外区设置。进一步使用相同势截断半径的双侧 FE-DVR/irECS 对照区分吸收与截断影响。昂贵的首个一维 DVR Arnoldi 尝试主动停止，`results/1d_dvr_irecs/status.json` 标明未完成；它没有被当作完成结果。随后采用独立验证的离子矩阵指数分裂完成对照，数据见结果表。

### D08：复质量桥接点的物理范数

irECS 桥接点坐标仍为实数，但它的总质量权重已包含复尾元贡献。仅按坐标实虚筛选后对系数平方求和，仍会多算桥接点。现在保留有限实区元素的质量权重，以 `w_inner/abs(w_total)` 还原物理内区概率。传播哈密顿量和表面振幅不受这一诊断修正影响；最终结果表从检查点重新计算该概率。早期 history 的近似范数保留原值，不篡改日志。

## 4. 逐时间步、逐模块的快照

运行：

```bash
make debug
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 \
HELIUM_LIBRARY=libhelium_debug.so python scripts/debug_modules.py
```

`results/debug_modules/` 中：

- 一维 12 个完整时间步，每步保存输入、势、动量、三个 Fortran 模块的输出和独立 SciPy 输出。
- 三维 6 个时间步，每步保存所有 Arnoldi 的 Hq、Q、约化 H、最终输出以及独立稠密矩阵指数的结果。
- `summary.json` 给出逐模块误差。编译启用边界检查、回溯和浮点异常检查。

大规模生产不把所有 Krylov 向量每一步写盘，而保存表面历史、定期完整检查点和诊断。发生新失败时，应在其最小可复现配置中启用上述完整模块快照；该设计同时满足排错可追踪与磁盘开销限制。

## 5. 已实施的独立检查

- 原子解析能级和氢样偶极矩；精确 Wigner/Gaunt 选择定则。
- ESSS 解析积分与独立 RK4；有限能带模型的总概率守恒；实验室系到旋转系的直接变换。
- 任意纠缠态的局域幺正/退相干不变性；Lindblad 迹、厄米性、正性和 negativity。
- Fortran FFT 与 SciPy FFT；缓存优化与逐模块原始路径。
- 三维 Fortran 张量哈密顿量与独立 Kronecker 稀疏矩阵：实网格、复网格、长度与速度规范、x/y/z 方向。
- Arnoldi 与稠密矩阵指数；自由波包通量；完整三维离散通量交换子。
- 连续传播与中断后恢复的一致性，参数更改时拒绝恢复旧检查点。
- Release 和 Debug 两种动态库运行同一测试集。最终日志见 `results/tests_release.log`、`results/tests_debug.log`。

## 6. 仍需生产级核验的内容

小规模 3D 的基态、本征残差或出现双峰，不等于长脉冲角分辨谱已完成所有收敛。需要进一步逐项提高 lmax、径向阶数、势截断半径、尾时以及有场规范对照。圆偏振多脉冲、修正后的 2p→3p 双光子手性链、实际环境退相干率目前没有完整的从头算收敛结论。

这里没有承诺去实现物理上不成立的信号，也没有把未执行的 Slurm 作业写成已验证结果。计算和待验收项目分别由配置、结果元数据和报告追踪。
