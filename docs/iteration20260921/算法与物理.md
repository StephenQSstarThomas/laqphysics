# 在线单电离谱与两脉冲制备

## 边界历史的内容

原 flux.npy 的维度为时间 × 内电子径向点 × 外电子表面模板 × 双电子角通道，complex128。它存储离散交换子源项 F(t)=[H(t),Θ₂]Ψ(t)。跨时间的复相位仍在，不能用各时刻 |F|² 相加替代能谱。

本程序约定 H_V=(p+A)²/2、E=−dA/dt。在偶极近似、外区势已截断的区域，Volkov 标签 k 守恒，机械动量为 k+A(t)。最终 A(T)=0 时，能谱横轴是 k²/2。仍需保留 Volkov 相位 ∫(k+A)²dt/2 及离子通道演化。双电子 tSURFF 的离子终态回传与边界积分依据 [Scrinzi 2012，§2.1](https://arxiv.org/pdf/1202.3590)。

## 本轮实现

指定终态通道 c 后，离子伴随态满足 i∂tχ_c=H_ion†χ_c，从终态反向计算。ECS 上径向末态使用解析 c-dual；不是把复坐标误当成实积分。最终振幅为相干积分

\[
b_c(k,\Omega)=i\sqrt{2}\int dt\,\langle\chi_c(t)\otimes v_{k\Omega}(t)|[H,\Theta_2]|\Psi(t)\rangle.
\]

这里 √2 是已使用的空间交换对称态因子。新流程只改变计算顺序和存储，不删掉核-电子或电子-电子动力学。

```mermaid
flowchart LR
  A[完整脉冲输入与离子末态] --> B[反向传播离子态]
  B --> C[每128步保存一个端点]
  C --> D[CPU进程独立回放小时间块]
  E[GPU正向传播双电子波函数] --> F[当前时刻边界源项]
  D --> G[立即离子收缩]
  F --> G
  G --> H[GPU或CPU累计复数Volkov振幅]
  H --> I[最终总谱与离子符合谱]
```

只保存端点会多计算约一遍小型单电子反向传播，换取大幅减小的存储。块回放互相独立，允许用 CPU 进程预取，与 GPU 推进重叠。把 ionic_block_frames 设为 1 会保存全部离子态并省去回放，但仍按文件上限分片；默认 128 更节省存储。

在线积分用梯形规则保留前一时刻的复振幅 integrand、当前积分 b、∫A 和 ∫A²。恢复检查点采用两个交替谱状态槽：先写未使用的槽，再原子提交引用它的波函数检查点。中途失败不会用新谱积分状态配旧波函数。

`spectrum` 模式的存储不随原始通量张量的全部维数增长；`projected` 模式另保存 Q_c,lm(t,r_s)，支持重新细化能量、角度和积分尾部。所有新数组用有界 NPY 分片或经大小检查的 NPZ；单文件默认 4 GB，禁止超过十进制 5 GB。波函数或单个谱检查点本身超限时，提交前拒绝该配置，不冒险先写巨大文件。

## π 脉冲和两能区

氢样 He⁺ 的 1s↔2p 偶极矩为 D≈0.3724677695 a.u.。当前圆偏振采用两个分量 F/√2，RWA 下的共振转移面积与等周期平均强度的线偏振一致。sin² 包络满足

\[
\Theta=D\int F(t)dt=D F_0T/2,\qquad
F_0=\omega/(D N)\quad(\Theta=\pi).
\]

故 N=201、ω=1.5 时 F≈0.02003579149；N=402 时 F≈0.01001789575。它们是同一 π 面积，不是同一强度或同一带宽。实际转移由连续态可参与的离子传播求出，不用 RWA 公式代替数值结果。

对第二束光新产生的中性电离，在弱场近似中，固定 π 面积使 F×T 近似固定。新峰宽度约随 1/T 缩小，积分产额约随 F²T 减小，但峰顶密度约随 F²T² 变化，因此单纯减弱并拉长第二束光不会同比降低峰高。必须同时检查峰高比和产额比。

初步调参的绝对总谱结果：

| 第一束 F / 周期 | 第二束周期 / F | 0.3/0.6 峰高比 | 能区产额比 |
|---|---|---:|---:|
| 0.12 / 24 | 201 / 0.0200358 | 2.314 | 12.729 |
| 0.12 / 24 | 402 / 0.0100179 | 2.296 | 25.153 |
| 0.08 / 48 | 201 / 0.0200358 | 4.015 | 10.951 |

这些先在与原对照匹配的小模型上计算，用于筛选。随后完成的 lmax=3、Lmax=3、156 径向点、n≤3 末态细化结果为：总谱峰高比 4.01582、产额比 10.96446、2p+1 符合谱峰高比 7.99412、绝对离子转移概率 99.85126%。三项谱求积检查也已通过。基态和绝对峰位仍显示从低阶模型到细化模型的修正，完整生产收敛仍需独立的 l、L、时间步、径向、边界和规范检查；详见 [本轮结论](../../results/preparation_20260921/SUMMARY.md)。

原弱泵浦模型的两能区峰高比仅约 0.0132。选中方案增强并延长第一束，第二束按 π 面积减弱；当前目标是绝对主峰优势，不通过逐曲线归一化“放大”旧峰。新第一束的完整支撑约 6.08 fs、强度 FWHM 约 2.21 fs，短于约 20.37 fs 支撑的第二束；它已不再是原先 12 周期的亚飞秒强度宽度。

## 单脉冲控制组给出的直接解释

选定脉冲在匹配的小模型中另做了第一束独立、第二束独立两项计算。以它们的实测量构造预测，不拟合比例或平移能轴：

- 旧能区：`第一束独立运行的 1s 符合谱 × P(1s→2p+1)`。预测产额 0.346466281，两脉冲实测 0.346463853，相对差 −7.01×10⁻⁶，归一谱形 L1 差 6.19×10⁻⁶。
- 新能区：`第二束独立运行的总 SI 谱 × 第一束后的中性基态存活概率`。存活概率 0.649675842；预测产额 0.0316412081，实测 0.0316413294，相对差 3.83×10⁻⁶。

[控制组对照图](../../results/preparation_20260921/figures/separated_pulse_controls.png)和 [数据](../../results/preparation_20260921/control_factorization_diagnostic.json)保留了全部比例来源。它们支持当前延迟制备中“旧电子谱形保持、离子末态转移；存活中性原子贡献新电离峰”的解释。这是小模型内的动力学核验，不能代替径向/角基收敛，也不是预先假定所有三脉冲情形都可因子化。

## 符合谱、总谱与后续探测

分别保存 P(E,c)、Σ_c P(E,c) 和按计算能窗归一的 P(E|c)。前两者使用绝对密度；最后一个只比较形状。有限离子通道和有限能窗的求和需要继续收敛，尤其不能把“单电离事件的筛选”与完整电子约化态混为一谈。

若电子离开之后只有离子演化 U_i，则 Tr_i[(I⊗U_i)ρ(I⊗U_i†)]=Tr_iρ。离子保迹噪声同样不能改变电子边缘态。符合后选择可以改变条件谱；进一步离子电离会改变被计为 SI 的事件集；后续脉冲产生新电子也会增加新的谱分量。这些情形均不能直接解释为旧电子的能量被远处的离子拉比振荡改变。

两脉冲制备接近“旧电子 × 2p+1 离子”的乘积情形时，后续纯离子驱动甚至会给该旧能区的各符合通道乘相同的能量无关转移系数。探测目标若是可分辨的 0.3 双峰，需要另外检查源的时间重叠、初始通道相关性和实际电子受力，而不是强制程序生成目标图形。

## 验证证据

- 在线 CUDA 小算例与原完整历史算法：末态波函数相对差 6.89×10⁻¹⁴，谱复振幅相对差 2.59×10⁻¹²；初态相位相同。
- 速度/混合规范、原乘积/通用耦合角基、块重建、分片边界、断点续跑和未提交谱槽均有直接回归。
- CPU 并行回放与串行结果逐复振幅比较；GPU 谱积分还与 NumPy 公式及检查点恢复独立比较。
- 更细三维模型在第 3737 步（448.421687 a.u.）与串行 LU/CPU 积分对照：双电子波函数相对差 0，已累计复谱振幅相对差 8.21×10⁻¹¹；比较只使用初态固定相位，没有谱拟合。这是同一时刻的算法执行对照，不是已经结束的光谱。
- 实际文件清单和最大全部随结果提供；源 ZIP 保留 SHA-256，超算脚本按其工作版本改动。
