# 完整收敛核验：运行协议与推导

本轮目标是在本机实际完成前次未通过/未执行的收敛轴，随后复核多脉冲和圆偏振。验收条件保持：主峰变化≤0.001 a.u.，各目标通道归一化谱 L¹ 差≤2%，同一能窗内产额变化≤2%。不作峰位平移，不用静态能量代替动态谱验收。

后续按用户提出的合作者交接方式，本机收尾范围调整为[最小验证交接](最小验证交接.md)：完成软件交叉验证和基准/近核细化长谱，其他完整收敛轴交由合作者继续。本文件仍保留完整计划及其原验收门槛。

## 迭代求解的精度与效率

物理哈密顿量、波函数、Krylov 基和真实残差均保持 complex128。可选 complex64 仅用于近似求解预条件步骤；其舍入使预条件操作不再严格线性，因此使用 flexible GMRES，保存各次预条件后的基向量，不能在最后把线性组合重新交给近似预条件器。

强场生产网格单步对照的波函数差约 3.7×10⁻¹³。完整 180 周期小模型回归的谱形差约 1.55×10⁻⁹、7.9×10⁻¹¹。算法根据真实双精度残差停止，而不是按预条件残差宣布通过。[Saad，1993](https://epubs.siam.org/doi/10.1137/0914028)

## 规范推导

本项目约定 E=−dA/dt，速度规范 H_V=(p+A)²/2+V。选紧支撑径向函数 f(r)，定义 ψ_g=exp(i A·r f)ψ_V，令 q=r(1−f)。对每个电子：

H_g=H_0+Σ_a A_a i[H_0,q rhat_a]+Σ_a E_a r f rhat_a
    +1/2 { A²(q/r)² + [q′²−(q/r)²](A·rhat)² }。

电子间局域势不变。内区 f=1 为长度规范，外区 f=0 回到速度规范，避免纯长度规范在 irECS 渐近区的问题。表面位于切换区之外，通量算符仍为速度规范形式；残余离子的反向传播必须使用相应 H_g。[Majety、Zielinski、Scrinzi，2014](https://arxiv.org/html/1408.6309v3)

数值实现独立投影这些连续算符，不用有限矩阵的幺正重标记冒充独立规范验证。CF4 的输入包含 A、E 和六个 A_a A_b 系数，分别作线性时间组合；空间依赖的二次项不能仅补一个全局 A² 相位。

角二次算符通过完整中间角壳层或 rank-2 张量构造，不能简单平方已经截断的偶极矩阵。测试包含纯长度/速度极限、两电子 Kronecker 对照、实域 Hermiticity、径向加密下的局部规范恒等式，以及不拟合末态相位的完整波函数对照。纯长度规范的独立波函数测试使用相同有限实盒；长谱对照使用内区长度、外区速度的混合规范。

## 圆偏振的通用耦合角基

交叉偏振两脉冲可访问 unnatural-parity 的总 L 态，因此不能沿用轴对称线偏振的自然宇称限制。通用基保留 (l₁,l₂,L,M) 的两类宇称，使用 Wigner 6j 直接构造角矩阵，并以原乘积球谐基逐矩阵验证。开发时发现并修正了新 Coulomb 公式遗漏的约化矩阵元相位；k=0 必须在所有宇称扇区等于正单位阵。这项新实现通过后才会用于生产，已有线偏振数据使用原已核验路径。

## 表面投影与求积

先保存 Q_{n,lm}(t,r_s)=Σ_{core} χ_n(t)* F(t)，再作动量和角度积分。这样能量、角度和积分尾部可独立细化。线偏振的 ±m 离子径向方程相同，允许精确折叠；一般圆偏振不作此折叠。耦合基在收缩时使用 CG 系数，不重建巨大的完整乘积张量。

直接积分与分解积分在完整 180 周期历史上的最大相对振幅差约 5.6×10⁻¹⁵。缓存记录原始帧哈希、参数签名和投影代码签名。提谱表面必须避开 irECS 桥接节点；该节点坐标虽为实数，质量权重仍为复数，不能误用实权重的 Volkov 测试函数。

本文件记录协议与已经验证的实现，最终通过/失败状态以实际完整谱的验收表为准。

## 实跑中的软件交叉验证

- 通用耦合角基与完整乘积角基的圆偏振短脉冲：复振幅相对 L² 差 2.09×10⁻¹³，未拟合相位。
- 纯长度与速度规范，在同一有限实盒中比较完整波函数；径向/角截断从 (p=4,l=2)、(6,3) 到 (8,4)，相对误差依次为 4.85×10⁻⁵、1.15×10⁻⁵、4.05×10⁻⁶。
- 混合规范与速度规范短谱：1s/2p0 的归一化谱形差 3.91×10⁻⁵ / 1.18×10⁻⁴，产额差 6.24×10⁻⁴ / 3.97×10⁻⁴。长强场规范比较另行运行。
- 稀疏 LU 与 CUDA flexible-GMRES 离子反向传播，在完整 180 周期小模型上的复振幅相对差 3.10×10⁻¹¹。该小系统的 GPU 后处理反而较慢，生产后处理使用 CPU。
- 修正 NumPy 布尔值不能写入 JSON 的缓存元数据错误；现在先序列化元数据，再提交缓存，实际两种角基的完整提谱和写盘均已通过。

以上误差证明相应代码路径相互一致，不能代替每个生产参数的收敛结论。测试记录与实际比较 JSON 均保存在 results/convergence_complete。

## 运行和审核入口

本机当前没有 `sbatch`、`sinfo`，直接用 CUDA/CPU 进程执行，不依赖 Slurm。`scripts/convergence_queue.py` 为每张选定 GPU 排定有界作业序列，等待前一进程退出后才复用设备；每项先验证实际历史，再提谱。输出锁防止重复写入。`scripts/convergence_quadrature.py` 等待真实谱和投影缓存后执行计划中预先列出的求积细化。

```bash
python scripts/audit_complete_convergence.py
# 有 Slurm 的集群：按当地要求添加 account/partition，指定持久 scratch。
export HELIUM_OUTPUT_ROOT=/persistent/scratch/helium-convergence
export HELIUM_SURFACE_ROOT=/persistent/scratch/helium-flux
sbatch scripts/convergence_complete.slurm
```

Slurm 入口冻结数值源码和已编译库，使用 complex128 物理算符与 complex64 预条件器；时限信号保存检查点，未完成传播不会提谱或宣称完成。脚本本机只做语法检查，不声称已在 Slurm 控制器上提交。验收 JSON 的 `all_defined_gates_passed` 仅指该计划中全部已定义的检查，不能外推到未列入计划的新频率、强度或开放系统模型。
