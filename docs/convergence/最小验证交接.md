## 2. 本轮确实发现和修正的问题

1. **表面跨越 ECS 桥接节点的隐患**：坐标为实数不代表质量权重为实数。现在拒绝复权重的表面模板，避免实权重 Volkov 投影不一致。
2. **新增通用角基的 Coulomb 相位**：开发时遗漏约化矩阵元相位，导致奇宇称扇区 k=0 不是正单位阵。逐矩阵对照定位并修正，随后才允许生产使用。早先线偏振结果使用另一条已验证路径。
3. **投影缓存的写入与依赖**：NumPy 布尔值触发 JSON 写入失败。改为原生布尔值，并先完成元数据序列化，再提交数据与完成记录；两种角基的真实 CLI 写盘均已验证。代码签名还补入提供库仑截断函数的 tdse1d.py，新增测试确认修改它会使缓存失效；本次截断函数本身没有改动，已有提谱沿用记录中的冻结代码。
4. **共享分区写满**：隔离失败尝试，校验可用检查点后恢复。一次补丁写入还使 implicit.py 被截断，已从 b335076 恢复后重新应用修改，并通过后续完整测试。大数据转入 /playpen1，迁移逐文件校验 SHA-256；不把损坏尝试纳入验收。
5. **不同能量网格的峰位审核**：对粗谱插值后再作局部峰拟合，会在插值折点引入假峰移。现在分别在两套原生能量网格上定位峰，再比较绝对能量；新增同一解析谱的粗/细采样回归。该修正不改动 TDSE 或谱数据。
6. **恢复失败后的信号清理**：参数签名检查抛出异常时，旧入口会遗留临时信号处理器。现在用 finally 恢复进入前的处理器，并在实际恢复失败测试中核验；成功传播的数值路径不变。

推导、误差数值和资源处理见[运行协议](运行协议.md)。原始两份 Markdown 和五篇 PDF 的 SHA-256 与 migration.json 一致。

## 6. 数据边界

Git 包含源码、配置、报告、小型谱和验证记录。flux、波函数检查点、投影缓存及编译快照留在服务器 scratch；交接清单提供其位置、大小、检查点 SHA-256，以及已有投影记录中的通量帧哈希。缺少这些大文件不影响从头复现，但不能直接从 Git 进行断点续跑或重新投影。

仅重做能量/角度求积时，可传递 projected_channels.npy、channel_projection.json 和对应代码快照；改变离子投影模型则需要原始 flux 或重新传播。缓存会检查代码和参数签名。

[资源估算](../../results/convergence_complete/handoff_resource_estimates.json) 按实际网格统计：13 项线偏振候选全部保留原始历史约 374 GiB，21 项多脉冲候选约 1,426 GiB，宜按批次安排持久 scratch。最大的多脉冲项仅 FGMRES 的 Q/Z 向量就约 14.4 GiB，算符、预条件器和工作数组还需额外显存；该数字不是峰值显存或运行时间承诺。

单电子能谱、条件离子通道和全空间波函数是不同的验收对象。离子局域保迹操作不改变已经离开的电子无条件谱；两光子电偶极 2p→3d 路径禁戒。不要为了符合原始预期而人为制造双峰或移动能量坐标。
