## 做了哪些核验

- Release / Debug 各 **96 项测试通过**；启用 CUDA 的专项组 **13 项通过**，含 CPU 对照。
- 实际圆偏振算例：新在线谱与原全历史算法的复振幅相对差 **2.59×10⁻¹²**。
- 更细模型第 3737 步：加速路径与串行对照的波函数相对差 **0**、部分复谱差 **8.21×10⁻¹¹**；通过后从该检查点继续到最终谱。
- 更细模型的角积分 12×16→24×32、能量步长 0.0005→0.00025、时间采样 1→2 步，**三项检查全部通过**，同时约束总谱与 1s、2p+1 符合谱。能量加密中最大通道形状 L1 差约 **0.0667%**，峰位差约 **1.70×10⁻⁷ a.u.**；时间采样检查中总产额最大相对变化 **1.84×10⁻⁶**。
- 单脉冲控制组：独立测得的离子转移概率预测旧 2p+1 谱产额的相对差 **7.01×10⁻⁶**；中性基态存活率预测新能区产额的相对差 **3.83×10⁻⁶**。

详细日志、真实残差、失败修复记录及适用范围见 [核验记录](validation/README.md) 和 [调试与交接](../../docs/iteration20260921/调试与交接.md)。细化运行两段调用合计约 85.8 分钟（使用已缓存基态），最大真实线性残差 9.9993×10⁻¹¹；抽样检查点中最大交换对称性误差 2.48×10⁻¹¹。

## 存储与 Slurm

新任务即时收缩边界源并相干累计谱，**不写原始 flux.npy**。本地细化模型若保留原始边界历史，仅该历史约 29.576 GB；现在包含恢复数据、投影历史和三项附加求积结果的整个运行目录约 **1.34 GB**，最大单文件为角积分加密谱，**345,968,154 字节（约 0.346 GB）**。单文件默认上限 4 GB、硬上限十进制 5 GB。

Git 内仅交付小型能谱 NPZ/CSV、图和元数据，可直接重画总谱与符合能谱。全角复振幅、波函数检查点和投影历史位于各运行 `export.json` 记录的持久计算目录；需要续跑或重新投影时再搬运这些文件。本轮没有批量删除旧通量数据。

已按用户提供的可运行脚本改为 GPU **1 卡 + 16 核**、CPU **64 核**，并完成语法及模拟调度接口检查；本地没有实际 Slurm 提交记录。生产批次 16 项的持久数组估算合计约 51.8 GB、最大单文件约 1.85 GB，建议预留 100 GB scratch。
